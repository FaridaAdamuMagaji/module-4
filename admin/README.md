## overview
The Flower Delivery website is a full-stack web application that allows users to view and manage flowers, complete with images and details. It includes both a backend (API built with Node.js/Express & MongoDB) and an admin frontend (React + Vite) for managing flowers.

## Features
- Add, update, and delete flower details  
-  Upload and serve flower images  
-  View all flowers with their data and images  
-  User authentication (JWT) for secure access  
- Responsive admin panel built with React  

---

## Technologies Used
- **Frontend:** React, Vite, TailwindCSS  
- **Backend:** Node.js, Express.js, MongoDB, Multer (for image uploads)  
- **Authentication:** JWT, bcrypt  
- **Deployment:** Render

## Setup and Installation

### Clone the Repository
```bash
git clone https://github.com/FaridaAdamuMagaji/module-4.git  
cd flower-delivery-app
```

## Frontend Setup
cd admin
npm install
npm run dev

## Usage

Visit the admin panel to manage flowers (add/edit/delete).

Fetch flower data from the backend API.

Uploaded images are served from the assets folder.
